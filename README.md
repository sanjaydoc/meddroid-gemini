# MedDroid for Gemini CLI

Free health tools for Gemini CLI, from [MedDroid](https://medicalandroid.com/#/setup?ref=gemini-ext), a free AI Health OS for you, your family, doctors, clinics and hospitals.

## Install

```bash
gemini extensions install https://github.com/sanjaydoc/meddroid-gemini
```

Then start `gemini` and ask, for example:
- "Use MedDroid to explain my HbA1c of 6.1"
- "Find hospitals near Adyar, Chennai"
- "How many calories in 2 idli with sambar?"

## Tools (14, all read-only)

| Tool | What it does |
|---|---|
| explain_lab_result | One lab value in plain words, in your language |
| explain_lab_report | A whole pasted report: values out of range, red flags, questions to ask |
| explain_prescription | What each medicine is usually for, as written. Never changes a dose |
| when_to_seek_care | Emergency now, see a clinician soon, or home care |
| find_clinics_near | Hospitals, clinics, labs and pharmacies near a place (OpenStreetMap) |
| find_teleconnect_clinicians | Verified MedDroid clinicians for video consults |
| teleconnect_booking_link | Booking link with fee and next free time |
| food_calories | Calories and macros for a meal, Indian foods included |
| health_calculators | BMI (Asian cut-offs), due date, ovulation, water, heart-rate zones |
| find_health_guide | MedDroid's free health guides |
| health_connect_devices | Which health devices work with MedDroid |
| meddroid_apps | MedDroid's free apps for families and clinics |
| clinic_savings_estimate | Yearly software savings for clinics |
| meddroid_info | What MedDroid is, plans and downloads |

No sign-in and no API key. The server keeps no health text, only usage counts. Fair-use limits apply.

**General health information, not a diagnosis.** In an emergency, call your local emergency number.

Other AI apps (Claude, ChatGPT, Cursor): https://medicalandroid.com/mcp/ · Support: support@medicalandroid.com
